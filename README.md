# Claude Code 개발 환경 도구 — 소개와 사용 설명서

Claude Code로 여러 프로그램을 혼자 만들고 관리하면서, 점검은 환경이 맡고 사람은 판단만 하도록 개발 환경을 다시 짰습니다. 이 저장소는 그 환경에서 사람이 실제로 보는 두 화면, **관제판(env-console)**과 **자산 인벤토리(cc-inventory)**의 소개 글과 사용 설명서를 공개용으로 올려 둔 곳입니다.

**바로 보기: https://manilow73.github.io/claude-dev-tools/**

## 무엇이 들어 있나

| 파일 | 내용 |
|---|---|
| `index.html` | 소개 글 + 관제판 매뉴얼 + 인벤토리 매뉴얼을 한 파일에 담은 문서. 그림과 글꼴이 모두 파일 안에 들어 있어 인터넷 없이도 열립니다 |
| `blog.html` | 블로그 본문에 붙여 넣는 소개 글 조각. 스타일이 블로그 테마와 섞이지 않도록 따로 가둬 두었습니다 |

## 두 도구는 무엇인가

- **관제판(env-console)** — 자동 점검 결과를 모아 사람이 판단할 것만 남기는 화면입니다. 맨 위 한 줄이 "루틴 경보 0건 · 지금 조치·결재 0건 — 닫아도 됩니다"처럼 결론을 말합니다.
- **인벤토리(cc-inventory)** — 이 PC에 깔린 스킬·에이전트·플러그인·훅을 스캔해, 무엇이 있고 실제로 얼마나 쓰는지 보여 주는 화면입니다. 사용 횟수는 지난 AI 대화 기록을 직접 세서 만듭니다.

두 도구 모두 개인 Windows PC에서 도는 로컬 도구이고, Python 표준 라이브러리와 정적 HTML로만 만들었습니다. 이 저장소에는 문서만 있고 도구의 소스 코드는 들어 있지 않습니다.

## 소개 글의 구성

소개 글은 2026년 7월 30일부터 10월 5일까지 실제로 부딪힌 일과 그때 바꾼 결정을 날짜순으로 정리한 기록입니다. 항목마다 "무슨 일이 있었나 → 바꾼 것 → 왜"를 적었고, 날짜와 사건은 모두 프로젝트 기록에 남아 있는 것만 옮겼습니다.

## 참고

- 문서는 Claude Code와 함께 작성하고 다듬었습니다.
